Methodology

The model uses monthly compounding and assumes the monthly contribution is made at the end of each month. The annual return is converted to a monthly rate using annual return ÷ 12.

For a starting amount P, monthly contribution C, monthly rate r and number of months n:

Future value = P(1 + r)n + C × [(1 + r)n − 1] ÷ r

When the assumed return is 0%, the contribution portion becomes C × n. The calculator uses that case directly to avoid division by zero.

What this result does—and does not—mean

  • The result is a mathematical illustration based on a constant assumed return.
  • It does not predict actual market returns or guarantee a future value.
  • It does not model taxes, fees, inflation, changing contributions, skipped contributions, withdrawals or market volatility.
  • Actual investment returns can vary from month to month and may be negative.
  • The calculator does not recommend a return assumption, investment product or contribution amount.
