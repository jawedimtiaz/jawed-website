Data, storage and privacy

  • Resume and job-description text are processed in this browser by the tool; this page does not send them to a server for analysis.
  • Use the tool only with information you are permitted to process in a browser-based tool. Avoid confidential employer, customer or other restricted information.
  • If you use Save Analysis, the generated analysis is stored in this browser's local storage until you delete it. Application Tracker entries and the theme preference also use local browser storage.
  • PDF and DOCX reading uses third-party browser libraries loaded from cdnjs. An internet connection is required for those file-reading features.
  • This tool does not make hiring decisions or predict hiring outcomes. Review all results and edit generated content before using it.
