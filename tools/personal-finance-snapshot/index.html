Methodology

Total spending = Essential + Discretionary + Debt payments

Monthly surplus = Income − Total spending

Savings rate = Monthly surplus ÷ Income × 100

Emergency reserve target = Essential monthly expenses × Target months

Months covered = Current emergency savings ÷ Essential monthly expenses

Net worth = Total assets − Total liabilities

The savings/contributions field is shown for context only; it is not used to project investment growth.

What this result does—and does not—mean

  • This is a snapshot based on the values you enter, not a financial diagnosis or recommendation.
  • There is no universal emergency-fund target built into the tool. You choose the number of months to illustrate.
  • A deficit shows that entered spending exceeds entered income; it does not identify the cause or prescribe an action.
  • Net worth is a point-in-time measure and depends on how assets and liabilities are valued and entered.
  • The tool does not calculate investment returns, retirement needs, inflation, taxes, loan amortization, credit scores or asset allocation.
  • Calculations run in the browser; there is no account, broker or transaction connection.
