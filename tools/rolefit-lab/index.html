Does your resume prove you can do this job?

An evidence-first alternative to a generic ATS score. The tool separates what the role asks for from what your resume actually demonstrates.

Experimental only.
Existing Career Match & Resume Review remains unchanged. This page is browser-only and stores only tracker data locally.

1. Resume evidence

This prototype deliberately starts with text so the test focuses on the methodology and UX, not file parsing.

2. Target role

Role requirements are converted into editable signals before scoring.

Role Signals

The tool first defines the job in plain language. You decide which signals are must-prove, important, or context.

Evidence Map

A keyword mention is not treated as proof. Strong evidence needs a concrete action, scope, outcome, or clearly stated responsibility.

Evidence Coverage

Priority fixes

Resume feedback

Prompt Studio

Independent prompts built around verification rather than invention.

Application decision

Why this tracker is different

It is designed around the question “what should I do next?” rather than simply recording status. The prototype keeps data in a separate local-storage namespace.
