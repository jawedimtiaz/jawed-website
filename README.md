# Jawed Imtiaz - Portfolio & Workplace Technology Hub (React + Vite)

A modern React Single Page Application (SPA) rewritten with Vite and TypeScript, preserving the professional portfolio, knowledge base, career tools, and interactive utilities of Jawed Imtiaz.

## Features

- **Home & Professional Experience**: Complete background, roles, certifications, and hands-on skills across IT support, Service Desk, Jamf, and workplace technology.
- **Interactive Tools & Utilities**:
  - **AI Prompt Builder**: Structured prompt generator for IT communications and troubleshooting.
  - **Career Match Resume Review**: In-browser keyword alignment and resume gap analyzer.
  - **Resume Bullet Strength Checker**: Action verb, metric, and clarity scorer for resume bullets.
  - **Interview Preparation Planner**: STAR storytelling vault and high-signal reverse questions.
  - **IT Troubleshooting Assistant**: Systematic diagnostic checklists for network, Apple, and Windows issues.
  - **Service Desk Note Formatter**: Audit-ready ITSM ticket note formatter.
  - **Ticket to Knowledge Base Draft**: SOP and self-service documentation generator.
  - **Personal Finance Snapshot**: Emergency fund, debt, and net worth assessment.
  - **Finance Planning Workspace**: Multi-view planning workspace for budget, goals, and retirement.
  - **Compound Growth & SIP Calculator**: Compound interest and wealth projection simulation.
  - **Inflation & Goal Planning Calculator**: Future goal cost estimator adjusted for inflation.
  - **Retirement Planning Calculator**: Corpus requirement and savings target calculator.
- **Practical Notes & Knowledge Base**: 30 technical guides and reference checklists searchable with instantaneous client-side filtering.
- **Jawed AI Assistant**: Search and Q&A engine grounded directly in website knowledge without external data transmission.
- **Curated Resources & Technical References**: Primary documentation links and reference-first workflows.

## Technology Stack

- **React 18** with **TypeScript**
- **Vite 6** dev server and bundler
- **React Router v6** for client-side routing
- **Responsive CSS** preserving typography, accessibility, and clean layout

## Development

```bash
# Install dependencies
npm install

# Start development server on port 3000
npm run dev

# Compile and build for production
npm run build
```
