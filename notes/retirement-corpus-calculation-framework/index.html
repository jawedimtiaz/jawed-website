Retirement Corpus: A Simple Calculation Framework

A retirement corpus estimate is a model, not a magic number. The useful part is making the assumptions visible so you can change them and see what happens.

Published: 2026-09-28 · Updated: 2026-09-28 · 8 min read

Start with the retirement-year spending number

The first step from the Phase 14N framework is to estimate annual spending at the point of retirement. If current annual retirement spending is S, years to retirement are n, and the planning inflation rate is i, a simple projection is:

Retirement-year spending = S × (1 + i)n

For example, a purely illustrative model using ₹6 lakh of current annual spending, 6% inflation and 15 years to retirement produces about ₹14.38 lakh of retirement-year spending. This is an example of the formula, not a forecast or recommendation.

Then choose a withdrawal model

There are several ways to estimate the starting corpus. A simple educational model is a finite-horizon withdrawal calculation: assume a retirement period, an annual spending need, and a return after retirement.

If annual spending is W, the annual real return is r, and the retirement horizon is N years, the present-value form of an inflation-adjusted withdrawal stream can be expressed using a real-return annuity calculation:

Corpus ≈ W × [1 − (1 + r)−N] ÷ r

When the assumed real return is zero, the formula simplifies to approximately W × N. This is a mathematical planning model; actual portfolios do not deliver a smooth annual return.

Why real return matters

Retirement planning mixes nominal rupees and purchasing power easily. A nominal return assumption and an inflation assumption can be converted into an approximate real return:

Real return = (1 + nominal return) ÷ (1 + inflation) − 1

For example, a 10% nominal return with 6% inflation is approximately a 3.77% real return. Using 10% directly as the retirement withdrawal return would overstate the purchasing power available to fund spending.

Illustrative corpus example

Suppose a hypothetical retiree expects ₹15 lakh of first-year retirement spending, plans for 30 years, and uses a 3% real return assumption. The simple finite-horizon model gives a corpus of roughly ₹296 lakh, or ₹2.96 crore.

If the same spending were modelled with a 2% real return, the estimated corpus would be higher. If the retirement horizon were shorter, the mathematical result would be lower. This demonstrates why a corpus number cannot be separated from its assumptions.

Real return3%Lower real returns generally increase the required corpus.

Do not confuse a corpus formula with a safe withdrawal rate

A simple annuity calculation assumes a smooth return and a defined horizon. Real retirement portfolios experience volatility and an uncertain sequence of returns. A bad sequence early in retirement can have a different effect from the same average return arriving in another order.

For that reason, a mathematical corpus estimate should be treated as a starting scenario, not proof that a particular withdrawal percentage will be safe. Published withdrawal-rate research may use different markets, periods, asset mixes, fees, taxes and assumptions, so those results should not be transplanted mechanically to every household.

Build three or more scenarios

A useful retirement model should make uncertainty visible. For example:

  • Base: your central spending, inflation and real-return assumptions.
  • Higher spending: higher retirement spending or healthcare allowance.
  • Lower returns: a lower real return assumption.
  • Longer life: an extended retirement horizon.
  • Combined stress: lower returns together with higher spending or inflation.

You do not need to predict which scenario will occur. The purpose is to understand how sensitive the target is to the assumptions.

Include income that continues after retirement

If a retiree expects reliable income from sources such as a pension, annuity, rental income or another documented stream, the planning model can treat that income separately from portfolio withdrawals. The key is to model the amount, start date, inflation linkage, taxes and reliability rather than simply subtracting an assumed percentage from the corpus.

Similarly, an emergency reserve and assets earmarked for other goals should not automatically be counted as retirement corpus.

From corpus target to savings target

Once a target corpus is estimated, the next question is how today's assets and future contributions could grow toward that target. That requires another model involving current retirement assets, contribution amount, contribution frequency, time to retirement and an assumed accumulation return.

This note deliberately stops before recommending an asset allocation or specific product. Those are separate decisions that should follow the goal, time horizon, risk capacity and applicable rules.

A repeatable calculation sequence

  1. Estimate today's annual retirement spending.
  2. Project that spending to the retirement date using an explicit inflation assumption.
  3. Choose a planning retirement horizon.
  4. Choose an explicit real-return assumption for the withdrawal model.
  5. Calculate a baseline corpus.
  6. Run lower-return, higher-spending and longer-horizon scenarios.
  7. Subtract only reliable retirement income that is actually expected to fund spending.
  8. Keep other financial goals and emergency reserves separate.
  9. Compare the target with retirement-designated assets.
  10. Review the model whenever a major assumption changes.

Use a calculator only after defining the assumptions

A spreadsheet or calculator can make the arithmetic easier, but it cannot decide whether your spending, inflation, return or lifespan assumptions are sensible. The assumptions should remain visible alongside the output.
